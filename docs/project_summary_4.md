## 1. 작업 목표 및 배경

기존 `MediGuide AI` 리포트 화면은 상단의 문진·XAI 영역과 하단의 복약 가이드·AI 상담창이 단일 우측 컬럼에 갇혀 있어 스크롤 시 좌측 공간이 비어 보이는 레이아웃 불균형이 존재했습니다. 또한 약품별 안내 텍스트가 긴 줄글로 뭉쳐 있고, 진료용 PDF 인쇄 시 불필요한 채팅 UI까지 함께 출력되는 문제를 개선하여 실사용성과 임상 가독성을 높이는 것을 목표로 진행했습니다.

이어서 Docker Compose(`docker-compose.fullstack.yml`) 기반의 풀스택 환경에서 백엔드·프론트엔드·AI 워커·인프라 컨테이너의 정상 기동과 실제 데이터 저장 흐름을 검증하고, 실행 로그 및 환경 설정에서 확인된 경고와 설정 항목을 정리했습니다.

## 2. 주요 UI/UX 및 기능 고도화 내역

### ① 하단 전체 너비(Full-width) 2열 그리드 개편
- **변경 내용:** 상단(`main-container`)은 `[1. 피부 병변 문진]`과 `[2. AI 병변 스크리닝 & Grad-CAM 히트맵]` 2단 구조를 유지하고, 리포트(`report`) 생성 시 하단 영역을 좌우 전체 너비(`max-width: 1280px`) 2열 그리드로 분리했습니다.
- **배치 효과:** 좌측에는 **`3. 맞춤형 FTU 정량 도포 및 복약 가이드`**를, 우측에는 **`리포트 연동 AI 복약 · 생활 Q&A 상담`** 창을 `position: sticky`로 병렬 배치하여 스크롤 시에도 복약 정보와 실시간 질의응답을 동시에 활용할 수 있도록 개선했습니다.

### ② 약품별 복약 가이드 구조화 및 등급 배지 분리 (`parseMedicationSummary`)
- **변경 내용:** 백엔드 응답 문자열에 중복 포함되던 `[약품명 | 성분 | 등급]` 헤더를 파싱하여 약품명 옆 **등급 배지(`스테로이드 1등급(초강력)`, `2세대 항히스타민제`, `스테로이드 5등급(약함)` 등)**로 분리했습니다.
- **가독성 개선:** `효능·효과`, `용법·용량`, `사용상 주의사항 및 DUR 부위 금기` 항목을 불릿 포인트로 자동 줄바꿈 처리하고, 개발자용 메타데이터인 **RAG 인용 근거 출처(문서 ID 및 유사도 점수)**는 `<details>` 접이식 패널로 수납했습니다.

### ③ 원클릭 복약 알림 등록 및 문진 상세 아코디언 복구
- **원클릭 스케줄 연동:** 각 약품 카드 상단에 `⏰ + 알림 등록` 버튼을 추가하여 클릭 즉시 해당 약품명과 부위별 권장 FTU 도포량이 좌측 `복약 · 도포 알림 스케줄러`에 등록되도록 연동했습니다.
- **문진 필드 복구:** 접이식 아코디언(`알레르기 · 기저질환 · 상세 메모 추가 입력`) 내부에 누락되어 있던 **발병 시기 및 연고 도포 이력 선택칸(`onsetDuration`)**과 **상세 증상 메모(`userMemo`)** 입력 필드를 복구했습니다.

### ④ 외용 스테로이드 중복 사용 DUR 경고 배너 추가
- **변경 내용:** 처방·보유 의약품 목록에서 외용 스테로이드 제제가 2종 이상 동시에 검출될 경우, 기존 안면부(`FACE`) 금기 경고 외에 **`⚠️ [DUR 동일 효능군 중복 주의]`** 경고 배너를 추가로 출력하여 전신 흡수 및 피부 위축 부작용을 예방하도록 강화했습니다.

### ⑤ 진료용 PDF / 인쇄 레이아웃 최적화 (`no-print`)
- **변경 내용:** 상단 `🖨️ 진료용 PDF / 인쇄` 실행 시 우측 AI Q&A 상담창 및 알림 등록 버튼에 `no-print` 클래스를 적용하여 인쇄 미리보기에서 자동으로 숨김 처리했습니다.
- **출력 결과:** 1페이지에는 환자 요약 헤더, DUR 안전 경고, Grad-CAM 히트맵 및 Top-3 예측 확률이, 2페이지에는 권장 FTU 도포량, 등급별 약품 가이드, 생활 습관 및 의사 질문 3선이 A4 규격에 맞춰 출력됩니다.

## 3. 풀스택 기동·연동 검증 및 경고/환경 설정 점검

### ① 컨테이너 빌드 및 기동 상태 확인
- `docker-compose.fullstack.yml` 빌드 및 실행 후 `mediguide_backend_full` (`Uvicorn running on http://0.0.0.0:8000`, `Application startup complete.`), `mediguide_frontend_full` (`VITE v8.3.8 ready`, `http://localhost:5173/`), `mediguide_mysql_full` (`healthy`), `mediguide_qdrant_full`, `mediguide_redis_full`, `mediguide_worker_full` 서비스 기동 상태를 확인했습니다.

### ② 프론트엔드 및 서버 파이프라인 연동 확인
- `http://localhost:5173` 브라우저 렌더링 및 분석 결과 화면 출력을 확인했고, 워커 로그에서 `Record #6` 및 `Record #7` 작업 수신과 `[RAG + DB 저장 완료]` 처리가 정상 완료된 것을 확인했습니다.

### ③ 경고 및 환경 설정 점검·수정 내역
- **`ai_worker/worker.py` (`QdrantClient` 연결):** HTTP 연결 환경에서 `QDRANT_API_KEY`가 전달될 때 발생하는 insecure connection 경고를 줄이기 위해 `QDRANT_API_KEY`가 있을 때만 `api_key`를 전달하도록 분기 처리했습니다.
- **`ai_worker/vision_model.py` (비전 모델 보정 모드 및 텐서 경고):** 커스텀 `.pth` 가중치 미존재 시 기본 `ResNet50` + 임상·병변 멀티모달 보정 모드로 동작하는 구조를 확인했고, `requires_grad`가 연결된 텐서의 스칼라 변환 경고를 줄이기 위해 `.detach()`를 적용했습니다.
- **`.env` 및 `HF_TOKEN` 세팅:** 로컬 HTTP Qdrant 연결 시 경고 방지를 위해 `QDRANT_API_KEY`를 비워 두고 `HF_TOKEN` 항목을 추가했습니다(기존 비밀번호·시크릿 키 및 `ALLOWED_ORIGINS` 항목 유지).

## 4. 트러블슈팅 (문제 발생 및 해결 과정)

| 발생 단계 | 문제 현상 및 에러 메시지 | 원인 분석 | 해결 방법 |
| :--- | :--- | :--- | :--- |
| **1. 코드 통합 중 컴파일 오류** | `[plugin:vite:oxc] Transform failed: [PARSE_ERROR] Unterminated string (src/App.jsx:715:31)` | 대용량 JSX 코드 복사·붙여넣기 과정에서 715번 줄 태그 속성이 중간에 절단되어 닫는 따옴표와 중괄호가 누락됨 | 파일 전체 구조를 재검수하고 마지막 닫는 중괄호(`}`)까지 무결성을 확인한 전체 코드로 재적용하여 컴파일 복구 |

| **3. 인쇄 미리보기 여백 밀림** | 진료용 PDF 인쇄 시 2페이지 하단 면책 조항 1줄만 3페이지로 넘어가 불필요한 빈 페이지 생성 | 하단 그리드 래퍼의 `padding-bottom` 및 `disclaimer-bar` 상단 여백이 A4 세로 출력 높이를 미세하게 초과함 | 하단 여백을 압축 조정하여 불필요한 3페이지 공백 없이 2페이지 규격 내 깔끔하게 수납 |
| **4. Qdrant HTTP 연결 시 API 키 경고** | `UserWarning: Api key is used with an insecure connection.` | 로컬 HTTP(`http://...`) Qdrant 연결에 `QDRANT_API_KEY`가 함께 전달됨 | `ai_worker/worker.py`에서 `QDRANT_API_KEY` 존재 여부를 분기하고 `.env`의 로컬 `QDRANT_API_KEY` 값을 비워 정리 |
| **5. 스칼라 변환 시 `requires_grad` 경고** | `UserWarning: Converting a tensor with requires_grad=True to a scalar` | `requires_grad`가 활성화된 텐서에서 스칼라 값을 직접 추출하는 과정 | `ai_worker/vision_model.py`의 스칼라 추출 구간에 `.detach()` 적용 |

- **UI 렌더링 및 반응형 레이아웃:** `localhost:5173` 환경에서 상단 2단(문진·Grad-CAM) 및 하단 2열(복약 가이드·AI Q&A 상담창) 정상 출력 확인
